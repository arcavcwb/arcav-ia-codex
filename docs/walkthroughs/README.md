# Registro de Walkthroughs y Entregas

Este directorio almacena los reportes técnicos detallados generados al finalizar cada tarea o Issue.
Cada archivo documenta: cambios realizados, contratos modificados, comandos ejecutados y resultados de pruebas.

## Índice

En orden de entrega. Cada walkthrough describe el proyecto tal como quedó en su entrega.

1. [`codex-mvp.md`](codex-mvp.md): paquete `@arcav-ia/codex`, `init`, `--doctor` y plantillas nativas de Codex.
2. [`backlog-routing-mvp.md`](backlog-routing-mvp.md): contrato JSON del backlog, validación y routing Luna/Sol/Astra en dry-run.
3. [`prd-to-backlog-mvp.md`](prd-to-backlog-mvp.md): PRD Markdown → backlog borrador (`backlog plan`).
4. [`sprint-planner-mvp.md`](sprint-planner-mvp.md): `sprint plan` determinista por prioridad y capacidad.
5. [`task-context-packets-mvp.md`](task-context-packets-mvp.md): paquetes de contexto acotados (`task prepare`).
6. [`task-execution-pilot.md`](task-execution-pilot.md): ejecutor piloto opt-in de una tarea (`task run`).
7. [`task-quality-gate-mvp.md`](task-quality-gate-mvp.md): quality gate del diff (`task verify`).
8. [`independent-review-handoff-mvp.md`](independent-review-handoff-mvp.md): handoff de revisión independiente (`task review`).
9. [`independent-review-execution-mvp.md`](independent-review-execution-mvp.md): revisor IA opt-in de solo lectura (`task review-run`).
10. [`codex-cli-pipeline-hardening.md`](codex-cli-pipeline-hardening.md): v1.2.0, endurecimiento del CLI de Codex y del pipeline; lista qué afirmaciones de los anteriores quedan desactualizadas.
